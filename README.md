# Pervent
Это пет-проект, который делается прямо сейчас:)

Для запуска на текущий момент необходимо скопировать себе репозиторий, а далее:

- npm install
- composer install
- symfony server:start -d
- docker compose up -d
- npm run build

Соответственно все соответствующие утилиты необходимо иметь на компьютере.
В обозримом будущем всё будет укомплектовано в Makefile, ну и php скорее всего будет занесён в докер.

## Что здесь есть?
На текущий момент на проекте реализованы несколько контролеров, в некотором виде twig-шаблоны. Используемый на текущий момент функционал: Doctrine Listeners, Symfony формы, Security бандл, EasyAdmin. Ожидаемые ближайшие доработки: добавить лайки (под них есть API Controller, сущности и сервис, но не написано отправка со фронта ajax-запроса), добавить workflow для описания состояний сущности Contest, добавить очереди, электронную рассылку. Использовать Symfony Secret для хранения приватной информации, написать тесты, фикстуры, CI/CD через Github Actions, доработать шаблоны до приличного вида, ну и деплой само собой)
